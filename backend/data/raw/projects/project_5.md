# MecAgent

Repository: https://github.com/Joseph-elias/MecAgent

MecAgent explores generation of CadQuery CAD scripts from object images.
It uses a vision-to-sequence architecture (ResNet + GRU) and post-processing to improve generated code validity.

Technical highlights:
- Vision-language style modeling
- Code generation from images
- Syntax repair and decoding constraints
- CPU-oriented experimentation under hardware limits

This project highlights my interest in multimodal AI and engineering-oriented automation.
