# MediNetFusion

Repository: https://github.com/Joseph-elias/MediNetFusion

MediNetFusion is a multimodal time-series classification project focused on early Type 2 diabetes prediction.
It combines CNN, LSTM, and XGBoost, then optimizes fusion weights and threshold for better F1 performance.

Technical highlights:
- Deep learning + gradient boosting ensemble
- Fusion weight optimization with constraints
- Robust evaluation pipeline (AUC, F1, confusion matrix)
- Imbalanced classification handling (focal loss)

This project reflects my strength in applied ML experimentation and model evaluation.
