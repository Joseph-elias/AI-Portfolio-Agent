# LegalChatbot

Repository: https://github.com/Joseph-elias/LegalChatbot

LegalChatbot is a full-stack Arabic legal assistant for Lebanese law.
I built a RAG pipeline that reformulates legal questions, retrieves relevant legal articles using Arabic SBERT embeddings, and generates grounded answers.

Technical highlights:
- FastAPI backend + React frontend
- Semantic search with Arabic SBERT
- LLM-based legal reasoning with constraints
- Source-backed responses with legal article references

This project demonstrates my ability to combine retrieval, multilingual NLP, and practical product delivery.
