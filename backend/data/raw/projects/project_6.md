# Queens-automation

Repository: https://github.com/Joseph-elias/Queens-automation

Queens-automation is a live assistant that detects a Queens puzzle board from screen capture, solves it, and auto-clicks solution cells.

Technical highlights:
- Computer vision for board detection and perspective correction
- Constraint-based solver logic
- Real-time interaction automation
- Windows-focused tooling and practical UX controls

This project demonstrates algorithmic thinking and end-to-end automation delivery.
