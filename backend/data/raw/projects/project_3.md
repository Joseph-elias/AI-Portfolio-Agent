# Patient-RAG

Repository: https://github.com/Joseph-elias/patient-rag

Patient-RAG is a lightweight medical-style RAG pipeline designed for patient-level QA with strict JSON outputs and guardrails.
The system is designed to be CPU-friendly while keeping responses grounded and auditable.

Technical highlights:
- Retrieval and generation constrained by evidence
- Structured output validation and post-processing
- Guardrails to reduce hallucinations
- GraphRAG-inspired patient knowledge graph construction

This project shows how I design safe, structured, and reliable AI systems.
